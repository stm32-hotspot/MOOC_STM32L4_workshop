# MOOC STM32L4 workshop

Disclaimer: This material was created in 2019 and is delivered as is.

## MOOC purpose 

The STM32L4 series is the leader in ultra-low-power 32-bit microcontrollers while offering high performance (100 DMIPS) thanks to its ARM® Cortex®-M4 core and high flexibility. Designers will especially appreciate its pin-to-pin compatibility with the STM32 family and its comprehensive development ecosystem. 

## Prerequisites
- The STM32L476 Discovery kit ([STM32L476G-DISCO](https://www.st.com/en/evaluation-tools/32l476gdiscovery.html)) is required for the hands-on exercises included in the course.
- Type A to typeB microUSB cable
- Type A to type B miniUSB cable
- Multimeter with current range below 1uA
- 3.5mm jack stereo headphones
- PC running Windows® with administrator rights and the following software installed:
    - current version of [IAR EWARM](https://www.iar.com/embedded-development-tools/iar-embedded-workbench)
    - current version of [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html)
    - [STM32CubeL4](https://www.st.com/en/embedded-software/stm32cubel4.html)
    - [STLink Utility](https://www.st.com/content/st_com/en/products/development-tools/software-development-tools/stm32-software-development-tools/stm32-programmers/stsw-link004.html)
    - [STLink Driver](https://www.st.com/en/development-tools/stsw-link009.html)
